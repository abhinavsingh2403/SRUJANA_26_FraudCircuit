AUDITABILITY

Tamper-evident review log

Review decisions are stored with a per-case SHA-256 hash chain so accidental or partial changes can be detected. Without an external anchor a database owner can rewrite the whole chain or delete its tail.

Use the "Verify audit chain" button in the review form to verify the active case's stored chain.
