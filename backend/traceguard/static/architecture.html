1. Ingestion Rails

Atomic Coordinator

Enforces zero partial writes. If any transaction in a 500,000-row batch has a corrupt timestamp, negative amount, or invalid schema, the transaction coordinator aborts the batch atomically to maintain 100% ledger consistency.

2. Detection Engine

Graph Motifs + XGBoost

Aggregates transactions into connected subgraphs. Detects circular layering (A → B → C → A) and multi-window pass-through bursts. Features an evaluated XGBoost model (94.6% precision) trained on point-in-time features with zero data leakage.

3. Audit & Ledger

SHA-256 Merkle Chain

Every compliance disposition (CONFIRMED_SUSPICIOUS, FALSE_POSITIVE) is cryptographically hashed and chained to GENESIS. Direct SQLite manipulation breaks hash verification instantly, guaranteeing non-repudiation.

4. Security Sandbox

Kali Linux Test Harness

Kept in an isolated test sandbox on a private virtual switch. Kali acts purely as an automated external client sending synthetic test cycles and probing injection defenses against our real API endpoints.
